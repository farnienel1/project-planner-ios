Home dashboard — full revamp

This is the screen almost every user sees first, so it gets the boldest treatment: the greeting and "Today's overview" are merged into one gradient hero (was two flat white cards), the two status pills now float and overlap the hero for depth, and the quick actions / up next sections keep every existing tile, label and behaviour but in a bigger, punchier card style.

Nothing functional changes: same refresh / notifications / profile buttons, same admin-only gear to customise the 3 overview metrics, same Warnings and Tasks pills (only shown when relevant), same Quick Actions grid — every tile, the Customise/Add/Remove/drag-to-reorder flow, and the Main Menu button — and the same Up Next list linking to My Schedule. Only the visual treatment changes.
