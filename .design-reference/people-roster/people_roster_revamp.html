Operatives & Managers — roster redesign

These two roster screens are the last ones still using the pre-revamp look (plain list rows, underline tabs, old avatar circles) while Projects, Small Works, Site Audit, Settings and the operative profile detail have already moved to the current card-based system. This mockup restyles the roster list only — every button, tab, filter option and action below is identical to what exists today, just re-skinned to match.

Nothing functional changes: same 3 tabs (Active / Inactive / Pending), same filter sheet with the same fields, same tap-to-open-profile behaviour, same swipe-left-to-delete on operative rows, same delete confirmation copy. Only the visual treatment (cards, spacing, pills, segmented control) is new.
