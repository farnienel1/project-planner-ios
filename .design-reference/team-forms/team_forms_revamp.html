No functional changes. All forms keep the same fields, required-field validation, and Save/Create/Cancel actions.
Create Manager / Create Operative: same header icon + copy, same fields (first/last name, email, phone, trade type picker with "Other" custom text, department/day-rate optional fields, notes), same disabled-until-valid Create button.
Edit Client: same Name/Email/Phone/Address fields, same "Save Changes" (disabled until name non-empty) and "Delete Client" confirmation alert.
Edit Material: same Date/Quantity/Unit/Description fields, same read-only "Added by"/"Last edited by" info, same permission check (only the booker can edit) and Save/Cancel toolbar.
Edit Wholesaler: same Name/Address fields, same Staff/Contacts list with "Add contact" opening the existing add-contact sheet, same "Delete Wholesaler" confirmation alert, same Save/Cancel toolbar.
Select People: same search bar, same Availability segmented filter (All/Available/On this job/Annual Leave) and trade filter, same radio-select rows with role chip, warning-triangle conflict indicators, expandable conflict rows with Acknowledge/Skip-day actions, and same Save (disabled until all conflicts resolved) / Back navigation.
