# iPhone 1.31 + 1.32: step by step, with terminal commands

Work top to bottom and tick each box. The row numbers (A1, B4…) match `docs/test-sessions/1.31-1.32.md`.
Commands are for a Mac in **Terminal** (zsh). Copy them line by line. Lines starting `#` are notes and don't need typing.
Where something can only be done in a browser or in the app itself, the step says so.

Order: **1** (web rules) and **2–3** (screens, decisions) can run in parallel. **4** needs 1 done. **5–6** come last.

```sh

brew install gh node
npm install -g firebase-tools

# Where your two repos live (change these if yours are elsewhere)
```

Add the two `export` lines to `~/.zshrc` if you want them in every new Terminal window:

**Who:** whoever deploys web. **Time:** about 15 min. **Warning:** `project-planner-f986c` is the live project, so publishing applies to every real user.


```sh

```

### 1.5 Confirm
- [ ] **Browser:** Firestore → **Rules → History**: the newest entry is today. (The Firebase CLI has no command that lists rules history.)

## 2. Screen checks, Part A (seeded data, no Firebase)

**Who:** someone with a Mac and Xcode 26.2. **Time:** 30–45 min.

### 2.1 Get the code
```sh
cd "$IOS"
git status                       # must say "nothing to commit"; if not, stash or commit first
git fetch origin
git checkout rulebook-1.32.1-sync
git pull
git log --oneline -1             # expect bf47e42 or newer
grep -m1 '^Version' docs/RULEBOOK.md    # expect: Version: 1.32.1
```

### 2.2 Get the right simulator (iPhone 16e, iOS 26.2)
```sh
xcodebuild -version                                   # expect Xcode 26.2 or newer
xcrun simctl list runtimes | grep "iOS 26.2"          # must print a line
# if nothing printed: install the runtime
xcodebuild -downloadPlatform iOS -buildVersion 26.2

# find (or create) the simulator and keep its id in $SIM
SIM=$(xcrun simctl list devices available | grep -A20 -- "-- iOS 26.2 --" | grep "iPhone 16e (" | head -1 | grep -oE '[0-9A-F-]{36}')
[ -z "$SIM" ] && SIM=$(xcrun simctl create "iPhone 16e" "iPhone 16e" com.apple.CoreSimulator.SimRuntime.iOS-26-2)
echo "$SIM"                                           # a long id like 9250FFF9-…

xcrun simctl boot "$SIM" 2>/dev/null; open -a Simulator
```

### 2.3 Build the app once
```sh
cd "$IOS"
xcodebuild -project "Project Planner.xcodeproj" -scheme "Project Planner" \
  -destination "platform=iOS Simulator,id=$SIM" \
  -derivedDataPath /tmp/pp-dd build | tail -5
# expect: ** BUILD SUCCEEDED **

APP="/tmp/pp-dd/Build/Products/Debug-iphonesimulator/Project Planner.app"
xcrun simctl install "$SIM" "$APP"
mkdir -p ~/Desktop/pp-test        # screenshots go here
```
(In Xcode instead: open `Project Planner.xcodeproj`, scheme **Project Planner**, device **iPhone 16e (26.2)**, ⌘B.)
